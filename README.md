# Maze Escape

A 25-level maze game for kids starring Zig the Bunny. Levels 1–9 are drawn by a young maze designer.

- Play: open `index.html`, then choose 2D or 3D.
- `maze-escape.html` is the 2D game; `maze-escape-3d.html` is the 3D version (uses three.js from cdnjs).
- Everything is plain HTML, CSS and JavaScript in one file each. Progress is saved in the browser.
